# DiceYahzee

5つのダイスを残して振り直し、基礎20点と出目の合計に役倍率を掛けた得点で相手を倒す1人用ゲーム。現行0.9.2。
最大2回の振り直しと、結果を使う判断が1ターンの中心です。

## 遊び方

Unity **6000.3.25f1** で `ParvaMirabiliaDice` を開いてPlay。
タイトルの「操作を練習する」で、低い目を残して役を作る固定出目の練習ができます。

- クリック・横ドラッグで残す目を選ぶ。残さない目だけ、右クリックで最大2回振り直す。3個残すと右ボタンが動くマウス図形を表示する。
- 右の9役から、クリックかホイールで使う役を選ぶ。ホイールは使用済みの役を飛ばして循環する。得点は floor((20＋5個の合計)×役倍率)。未成立とチャンスは倍率1。
- 着地後に役の成立を通知。役の種類に応じた演出で、揃ったダイスと手の強さを伝える。
- ボタン以外の画面を下へ引くとダイスが下がり、離すと発射して確定。双方の点数の低い方の半分（切捨て）を、両方の攻撃から同じだけ軽減して同時にダメージ。
- 各役は1回ずつ。9欄全てを使い切った側は次ターンに役を再使用できる。
- 「持越」は対局中1回。右の操作を選ぶと出目持越の予告に切り替わり、もう一度選ぶと解除。下へ引いて発射した時にだけ消費する。今回も自分の点数で攻撃し、相手の点数を全て受ける。生き残れば次ターンは同じ5個と保持状態から、さらに2回振り直せる。
- 双方体力240。どちらかの体力が0になるまで続行。同時KOは0に丸める前の残HPが多い側の勝ちで、同じなら引き分け。

相手は同じ役・得点・役欄の周期で、自分の出目だけから判断します。「標準」は見えている役・一致した目・高い目を残して最大1回振り直し、「上級」は従来の厳密な期待値判断で最大2回、「上級・大役」は大きい得点を重視します。初回と振り直しの実出目を短く再生し、役と点数を公開します。結果は人間の投擲前に固定し、人間の出目を見て変更しません。

## 操作

| 入力 | 操作 |
| --- | --- |
| クリック・横ドラッグ | ダイスを残す / 解除 |
| ホイール | 上で前・下で次。使用済みを飛ばして循環選択 |
| 右クリック | 残さなかった目を振り直す |
| ボタン以外を下へ引いて離す | 選択中の役で5個全体を発射して確定 |
| 1〜5 | ダイスを残す / 解除 |
| Space | 残さなかった目を振り直す |
| 攻撃演出後のボタン以外のクリック | 次のターン |
| Enter | この結果を使う / 次のターン |
| Tab、矢印 | 表示中の画面のボタンを選ぶ |
| Esc | 画面を閉じる / メニュー |

メニューには音と成立演出の設定、ルール、素材クレジットがあります。
下へ引く操作は28 Canvas単位以上の下移動で離すと確定し、届かなければキャンセルします。振り直し・結果使用のボタンは撤去し、押して18px下へ引くマウス図形と、42px下へ動く3段の山形を表示します。ホイールは内側だけ上下4px動きます。ダイスは面・角を含む全面からドラッグできます。
攻撃は被害量に応じて軌跡・衝撃・揺れを強め、接触した瞬間にHPと音を合わせます。攻撃が終わるとクリック図形を表示し、背景・ダイス・無効な領域のクリックで次へ進みます。次へボタンはありません。演出中の早いクリックとモーダル中の入力は受け付けず、モーダル中は演出を止めます。
下引きのマウス図形は下げ切った場所で消え、定位置から再表示します。ウェブ版の日本語と大きな得点は同梱フォントで表示し、ダイス音は最初の転がりだけを再生します。
モーダル表示中と振り直し中は、ホイールで役を切り替えません。
自分で選んだ役は、そのターン中は振り直しても維持します。次ターンは最も得点が高い未使用役から選べます。
「持越」は対局中の出目持ち越し操作です。対局の中断保存は行いません。音と演出の設定は保持します。
暗い卓の左右に背景のない細い役レールを対称配置し、役名のコントラストと行間で一覧性を保ちます。相手の5個の出目・役名・小さな計算式・得点を中央に縦配置し、太いHPバーの中にHPを表示します。役名と状態にはNoto Sans JP、ゲーム名と大きな得点にはAoboshi Oneを使います。持越は中央の金色の操作として置き、選択中は5個の小ダイスを中に表示します。保持は鍵、残り振り直しはHPバー下の金色の点、下引きと右クリックは右側のマウス図形で示します。説明文は遊び方へ置き、対戦画面は役名・数値・操作名・図形で伝えます。
1280×720を基準に4:3とワイドへ拡縮します。

## 開発と検証

開いているUnityプロジェクトを閉じず、隔離した検証コピーを使います。

```powershell
./scripts/Prepare-ValidationProject.ps1
./scripts/Test-Game.ps1 -Platform EditMode -ProjectPath D:\MimoGame\.validation\ParvaMirabiliaDice
./scripts/Test-Game.ps1 -Platform PlayMode -ProjectPath D:\MimoGame\.validation\ParvaMirabiliaDice
```

結果は実行ごとのXML・ログへ保存。失敗、結果欠落、0件実行は失敗扱い。
旧画面のテストは旧仕様へ明示的に切り替え、現行の操作テストとは区別します。
実行時の描画確認は `scripts/Build-Windows.ps1` と任意の `-arcaneSmokeOutput` 診断で行います。
Web共有版が必要な場合は `scripts/Build-Web.ps1 -ProjectPath D:\MimoGame\.validation\ParvaMirabiliaDice` でビルドし、`Builds/Web-*.zip` を展開して `index.html` を含むフォルダー全体を静的HTTPサーバーへ配置します。
ビルド成功や自動方針の勝率を、要求品質や人間の面白さの証明には使いません。

現行仕様は `docs/GAME_DESIGN.md`、検証結果と確認範囲は `docs/TEST_REPORT.md`。
同報告§19以前の記録は旧版の証跡です。0.9.2の最新検証と実行版の確認範囲は§20に記録しています。
役倍率と同時ダメージの採用は `docs/DESIGN_HISTORY.md` §12、0.8.0の敵・入力・攻撃演出は§13、0.9.0の持越と画面構成は§14、0.9.1の情報配置は§15、0.9.2の画面改修は§16に記録しています。

AI生成画像は使用していません。以前の実行版は新ルールを含みません。
