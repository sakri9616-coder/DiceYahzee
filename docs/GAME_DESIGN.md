# GAME_DESIGN — DiceYahzee

現行仕様：0.2.4 / 2026-10-21（HP1500・出目合計×役倍率・ヤッツィー900点固定・振り直し温存の回復・チャンスの被害入れ替え・NPC5段階。オンライン対戦の進行は `NETWORK_DUEL_PLAN.md`）。0.5.0の仕様とコードは `logs/quality-baseline-0.5.0` に保持。
要求品質は「Steamセールスランキングで一位を取れる水準」。ゲームデザイン、UI/UX、ビジュアルと操作感を評価する。実行版の作成や自動テストの成功を品質達成と取り違えない。

## 1. これは何か

5つのダイスを残して振り直し、出目の合計に役倍率を掛けた得点で相手を倒す1人用の短い対戦ゲーム。
初回の投擲は自動。残すダイスを選んで振り直す判断を最大2回行い、最後に結果を使う。
通常は低い方の点数の半分（切捨て）を両方の攻撃から同じだけ軽減し、同時にダメージを与える。どちらかのHPが0になるまで続ける。

役は9欄それぞれを1回ずつ使い、全欄を使い切った側だけ次ターンに再使用可能になる。チャンスも同じ制限を受ける。
低い目にも役を作る材料として価値を持たせつつ、役が変わらない振り直しや未成立の手でも出目の合計が結果へ反映される。
卓に重ねた右の9役表で、クリックまたはホイールから使う役を選ぶ。左は相手が使った役を示す。中央に現在の役と点数を表示する。
対局中に1回だけ、通常どおりの被害を交換しつつ、同じ出目から次ターンを始められる。
AI生成画像は使用しない。卓の革にはPoly Havenの既存フリー素材を使い、ダイスと画面部品は明確な形と配色で構成する。

## 2. コアルール

### 2.1 基本値

| 項目 | 値 |
| --- | --- |
| ダイス | 5d6 |
| HP | 自分1500、NPCは難易度別に1250／1750／2000／2250／2750 |
| 振り直し | 双方最大2回 / ターン（ヤッツィー成立の次ターンは+1回、最大3回） |
| 回復 | 確定時に使わなかった振り直し1回につき40。被害適用前、最大HPまで。双方同条件 |
| ターン | どちらかのHPが0になるまで続行 |
| 得点欄 | 9種類、各1回 / 9欄の周期 / 各プレイヤー |
| 得点 | 5ダイスの合計×選択役の倍率。ヤッツィー成立は900点固定。未成立は×10 |
| 通常の被害 | 両方の点数からfloor(min(P,N)/2)を共通軽減して同時に攻撃。チャンス宣言で受け手を入れ替え |
| 出目の保存 | 人間側が1回 / 対局 |
| 勝敗 | 片側HP0で敗北。同時KOは丸める前の残HPが多い側の勝ち、等しければ引き分け（奇跡） |

### 2.2 役と得点

| 役 | 条件 | 成立倍率 |
| --- | --- | --- |
| ペア | 同じ目が2個以上 | ×15 |
| ツーペア | 異なる2組のペア | ×20 |
| スリーカインド | 同じ目が3個以上 | ×20 |
| フルハウス | 3個と2個の異なる同目 | ×25 |
| 小ストレート | 異なる4つの連続した目 | ×20 |
| フォーカインド | 同じ目が4個以上 | ×30 |
| 大ストレート | 異なる5つの連続した目 | ×25 |
| ヤッツィー | 同じ目が5個 | 成立時900点固定 |
| チャンス | 条件なし | ×10 |

5個全ての出目合計に、成立した選択役1つの倍率を掛ける（整数どうしなので端数は出ない）。
例：1・1・1・1・6のフォーカインドは10×30＝300点。6・6・5・4・2のペアは23×15＝345点。
ヤッツィー成立だけは900点固定とする。低い目の完成役にも価値を残し、同じ役の出目改善も得点へ反映する。

ヤッツィーの出目をペア、スリーカインド、フォーカインドの欄で使うこともできる。使った欄だけを消費する。
未成立の未使用役も選べる。この場合は一律×10、得点は出目の合計×10で、その欄を消費する。
フルハウスの出目はツーペアにも該当する。ヤッツィーはフルハウスとツーペアには該当しない。
9欄が全て使用済みになった側は次ターン開始時に全欄を戻す。HPと保存の使用状態は戻さない。
ヤッツィーが成立すると、次ターンの振り直しが1回増える。9欄が戻ってヤッツィーを再び成立させれば、この効果も繰り返せる。

### 2.3 ダメージと予告

相手は人間の投擲前に、自分の5ダイス、最大2回の振り直し、役の選択を終える。
役名、点数、その根拠となる実際の5ダイスをターン開始時から公開し、人間の投擲や保持を見て変更しない。
初回と各振り直しの実出目・保持マスクを不変の履歴へ保存し、1段階0.18秒で再生してから最終予告と出目を揃える。再生用に別の目を作らず、保持した目は振り直さない。
NPCは難易度名にかかわらず、残り最大2回の全出目を確率付きで列挙する上級（Expert）の期待値方針で役を選ぶ。負傷しているときは、停止して残す振り直し1回を40の回復価値として期待値に含める。満HPでは回復価値が0なので、従来の得点だけの方針と同じになる。難易度の違いは相手の初期HPだけで、1250／1750／2000／2250／2750の5段階。標準（Balanced）や大役（Aggressive）の簡易方針は通常起動では使わず、Carefulも内部互換用に保持して画面には出さない。NPCもチャンスを宣言でき、被害の受け手を入れ替える式反転を適用する（プレイヤーが任意の低い目を狙う遊びを許容）。
人間とNPCに同じ得点と役欄の周期を適用する。乱数は別ストリームで、人間の振り直し回数がNPCの将来の出目を変えない。

点数をP、Nとし、共通軽減A＝floor(min(P,N)/2)。相手への被害はP−A、自分への被害はN−A。チャンスを宣言した側は被害の受け手を入れ替える。双方がチャンスなら入れ替えは打ち消し合い、通常どおり計算する。
例：P＝560、N＝700ならA＝280、相手へ280・自分へ420ダメージ。同点320なら双方160。低い側の攻撃も残る。
確定時、被害を適用する前に、使わなかった振り直し1回につき40回復する。回復はその側の最大HPで止まる。両者とも基本2回（ヤッツィー成立の次ターンは3回）なので、最大120まで回復できる。プレイヤーとNPCで扱いは変えない。
例：HP1400で2回残して確定すると80回復して1480になり、そこから被害を引く。HP1490なら10だけ回復して1500で止まる。
HPは同時に減らす。同時KOでは回復を含む0に丸める前の残HPを比較し、理由行は「同時KO（残HP判定）」と表示する。HP100/200に攻撃105/215を受けたときは残HP−5/−15で自分の勝ち、同値だけ引き分け（奇跡）。
攻守への配分、守護、魔力は使わない。
通常の被害を確定前に、その被害を受ける側のHPバー内の予測として表示する。チャンスの入れ替えと持越は遊び方で説明する。予告の役名だけで信頼を求めず、実際の出目と基礎点・出目合計・倍率が一致することを判断材料にする。

### 2.4 出目の保存

投擲後の確定前に画面中央の「持越」を選ぶ。金色の操作面に小さな5ダイスを収め、手の括弧と次ターンの出目予告でもモードを示す。同じ操作で解除でき、下引きからの発射時だけ1回分を消費する。

1. 選択中の役で通常どおり点数Pを計算する。敵の予告点数をNとする。
2. 今回は通常どおり共通軽減を適用した被害を同時に与える。
3. 双方の選択役を消費し、現在の5個の目と保持状態を保存する。
4. 生存していれば、次ターンは保存した目と保持状態を自動で取り出し、さらに2回振り直せる。最初の自動投擲は行わない。

持越は攻撃をやめる操作ではない。今回も攻撃する代わりに通常の被害を交換し、今の手を起点として次の役を狙う。
保存によって使った役を戻すことはなく、保存も再使用できない。9欄を使い切った場合の通常の更新は適用する。決着した場合は保存を失効させる。
例：P＝56、N＝70なら、通常も持越もA＝28で敵へ28・自分へ42ダメージとなり、生き残れば次ターンの初手に同じ5個を持ち越す。
実行前の表示に、自分が受ける被害と相手が受ける被害をそれぞれのバーの行へ出し、次ターンに2回振り直せることも含める。

## 3. 画面と操作

### 3.1 通常画面

暗い卓面を画面の土台とし、左右に188幅・390高の背景のない役レールを重ねる。左に相手の使用役、右に自分の9役を配置する。役名は明るい文字と行間で読みやすくし、選択中の行だけ金色で強調する。中央には自分の5ダイス、選択中の役と点数、金色の持越操作を置く。ゲーム名と大きな点数はAoboshi One、役名や状態はNoto Sans JPを使う。上下のHP文字は厚さ36のHPバーの中に配置し、その1行に側の名前・現在HP・上限を出す。回復中は「+40」を緑（`SDHealInk`＝27,91,64）、被害中は「−35」を赤（`SDDamageInk`＝193,39,45）で続けて出し、表示する数字は今いる段階のものだけにして両方を同時には並べない。残りの振り直しは下の金色の点3個で示し、通常ラウンドは2個だけ点灯する。
得点と相手の得点は太字と暗い縁取りで読みやすくする。被害は、その被害を受ける側のバーの文字として同じ寸法・同じ太さで並べ、色だけで区別する（`SDDamageInk`＝193,39,45。バーの塗りより暗い赤で、塗りの上でも排水帯の上でも読める）。HPが減る間も同じ行の同じ位置に減少量を出し、数字が別枠へ移らないようにする。使用済みの役名は暗い色にして、使える役との差を明度で示す。持越の選択を切り替えると、中央の操作から輪が広がる合図を出す。
KenneyのCC0 UI・Input Prompts・Game Iconsを使用する。説明文は遊び方だけに置き、通常画面は役名・数値・操作名・図形で伝える。
相手の予告は中央で、44px角・間隔51pxの実ダイス5個、役名、出目合計×倍率の内訳、強調した得点の順に縦配置する。暗い予告ウィンドウは置かない。相手が消費した役も左の役レールへ反映する。
役の一覧では現在選択中、成立、未成立、使用済みを区別し、選択に別画面を必要としない。
未成立の役は消さず、出目合計×10を使えることを表示する。使用済みの役は選択できない。
残したダイスは静止し、鍵の図形で保持を示す。右側のマウス図形で下引き・右クリックを伝え、独立した振り直し矢印は置かない。残していないダイスだけが振り直される。

最も高い使用可能な点数を既定にするが、着地後に別の欄を選んで将来の欄を温存できる。
通常確定の被害も、確定前の予測と同じバーの行へ赤い数字として続けて出す。持越を選択すると次ターンへ引き継ぐ出目を予告し、中央の操作面に5ダイスを見せ、次ターンにダイスへ戻す。詳細は遊び方に明記する。戦闘に関係しない設定や素材情報はメニューへ置く。

### 3.2 役成立の演出

ダイスがすべて着地してから役名と点数を表示する。
役を構成するダイスのまとまり、短い音と拡大で成立を通知する。役の種類に応じて演出の規模と形を変える。
小さなペア、大きな同目の集合、ストレートの並び、フルハウスの3個と2個を視覚で区別する。
振り直しで手の強さが変わったとき、その変化を結果の役名・点数と対応させる。
投擲途中に確定済みの内部結果を先に表示しない。保持を切り替えただけでは通知しない。
初回、振り直し、次ターン開始で同じ投擲の方向性を使う。余分な確認ボタンは追加しない。
「成立時の動き：控えめ」では移動・拡大・光の飛散を抑え、成立した役と点数は同じように伝える。

### 3.3 攻撃の演出

相手への実被害（DamageToNpc）を250未満、250〜449、450〜699、700以上の4段階に分ける。5個のダイスは下引きから `LoadingEnd = 0.12` で動き始め、`CollisionTime = 0.24` で敵に接触し、`HitStopEnd = 0.28` の静止後に押し込み、`ContactTime = 0.64` で相手の HP へ到達する。攻撃演出は `Duration = 0.90` で原状へ戻る。HP は同じ `HealthPresentation` の時計を使い、0.28〜0.64 に回復、0.64〜1.24 に被害を動かす。軌跡、輪、短い放射線、局所と画面全体の短い光、敵ダイスと得点プレートの反動、ダメージ数字の大きさを被害量に合わせる。放射線は上部HUDに残らない範囲で消す。「控えめ」では飛行と点滅を避ける。

### 3.4 入力

クリックで残すダイスを切り替える。横にドラッグすると、通過したダイスを同じ保持／解除状態へ揃える。
ホイール上で前、下で次の役へ切り替える。使用済みの役を飛ばして未使用の役だけを循環し、モーダル表示中と振り直し中は切り替えない。
ターンの初期選択は現在の出目で最も得点が高い未使用役。自分でクリック・ホイール選択した役は振り直しても維持し、次ターンに初期選択へ戻す。成立通知は選択役とは独立に、実際に揃った最も強い未使用役を示す。
右クリックまたはSpaceで、残さなかったダイスだけを振り直す。
ボタン以外の画面を下へ引くと5個のダイスが下がり、離すと選択した役で発射して確定する。下への移動が28 Canvas単位以上で離したときに実行し、届かなければキャンセルする。
下引き中は保持状態を元に戻し、1回の離す操作から確定を1回だけ呼ぶ。面・角を含む各ダイス全面もドラッグ対象とする。
振り直し・結果使用ボタンを撤去し、マウスの押下と3段の山形で操作を示す。1.8秒周期でマウスと矢印が一緒に42px下へ移動し、両方が完全に消えてから初期位置へ戻って再生する。見えている間は上へ戻らない。3個保持すると右ボタンが動くマウス図形へ切り替える。ホイール図形は内側だけ上下4px動く。投擲中・確定後・モーダルでは操作ガイドを隠す。
1〜5は保持の切り替え、Spaceは振り直し、Enterは結果を使う／次へ。動きを控えめにする設定ではガイドを静止表示する。
攻撃終了後はクリック図形を表示し、ボタン以外の背景・ダイス・無効領域のクリックで次ターンへ進む。次へボタンは置かない。演出終了前の押下と同じ入力の二重実行を防ぐ。
モーダル表示中は対戦への入力と演出の時間を止める。閉じたキーが対戦へそのまま流れないようにする。
タイトルから開始、ルール・練習、結果から再戦・タイトルまでつなぐ。
4:3とワイドでも、9役・ダイス・点数・被害・主要なボタンが重ならないことを描画で検証する。

## 4. 採用した考え方と撤去した前提

0.5.0以降のプレイ評価と0.7.0の採用判断を反映し、振り直しと役の成立を維持しながら次を改めた。

- 別画面の役選択を、右側の9役の常時選択へ変更。ホイールで未使用の役を循環選択できる。
- 固定得点だけで決まる手を、出目合計×役倍率へ変更。役が変わらない出目の改善も結果に反映する。
- 差だけの被害と6ターン判定を、共通軽減後の同時ダメージ・KOまでの対戦へ変更。
- 9欄の使用制限を維持し、使い切った側だけ次ターンに欄を戻す。
- 右クリックの振り直しと、横ドラッグの保持・下へ引いて離す発射確定を追加。振り直しと結果使用のボタンは撤去した。
- 相手の実出目を最初から表示し、役の強さに対応する成立演出を使う。
- 1回の出目保存を、通常の被害と引き換えに次ターンへ手を持ち越す操作として追加（当初は全攻撃の交換として導入）。

[Hasbro公式ルール](https://www.hasbro.com/common/documents/dad2af551c4311ddbd0b0800200c9a66/8302F43150569047F57EB8D746BA9D86.pdf)の最大3投、保持、得点欄1回制、チャンス1回、失敗時0点を参考にした。
[Dice Throneの公式ルール](https://dice-throne.rulepop.com/#offensive-roll-phase)では、出目の条件を満たす攻撃を選ぶ。目標を見せながら実出目で確定する考え方を参考にした。
[Dicey Dungeonsの開発記録](https://diceydungeons.com/blog/2018/04/20/version-5.html)では、ダイスを埋めると確認なしで発動する変更により操作感が改善したと報告している。直接操作の入力設計の参考にした。
[公式Daggerの仕様](https://wiki.diceydungeons.com/doku.php?id=equipment:dagger)は3以下の目を受け入れる。低い目の意味は文章で飾らず、結果に関わる規則で作る。
[同作のBurnの開発記録](https://diceydungeons.com/blog/2018/06/08/version-8.html)はHPを払ってダイスを使う選択を記す。本作の保存は、具体的な被害と具体的な次の手を交換する独自の設計である。

これらの適用判断と本作の9役・出目合計×役倍率・HP対戦・保存は本作の設計であり、参考ゲームの公式規則そのものではない。
魔力、強化、守護、祝福、攻守分割と独自用語による装飾は現行対戦へ戻さない。

## 5. 実装と検証

現行は `Core/ScoreDuel.cs`、`Core/ScoreHoldPolicyExact.cs` と `Presentation/GameFlow.ScoreDuel*.cs`。
旧MatchEngine・魔力・祝福関連は比較検証用として保持するが、通常起動では構築しない。
旧画面の回帰テストは明示的に旧仕様で実行し、現行画面の検証とは分ける。

自動試合のループガード110は、最大HP2750と、共通軽減後に成立し得る最小被害25からceil(2750/25)で求める内部値で、ゲームのターン上限ではない。回復が続けばこれを超え得るため、呼び出し側は実際の決着で必ず抜ける。ターン数による残HP判定は行わない。同時KOだけ回復を含む丸める前の残HPを比較し、理由行に「同時KO（残HP判定）」と表示する。
検証対象は、役ごとの倍率とヤッツィー固定点、未成立の出目合計×10、通常／同点／保存の同時被害とrawHPのKO判定、使わなかった振り直し1回につき40の回復（被害前・最大HP止まり・両者同条件・NPC側も）、役欄の再使用、保存の復元と失効、NPCの予告固定と負傷時の回復評価、入力の二重実行防止、着地と演出・表示の同期、HPバーの回復→被害の2段階、オンラインの自分の回復プレビューと相手の非公開を含む。
