# DiceYahzee 開発状況

最終更新：2026-10-12 / 現行ゲーム：0.9.2

5個のダイスを振り直し、選んだ役の倍率で得点を決め、下引き・離す発射で相手へぶつける対戦型ゲーム。標準の敵は実際の初回出目から保持を判断し、最大1回振り直す。上級には従来の強い期待値方針を残す。得点は floor((20＋5個の出目合計)×役倍率)。双方の低い得点の半分を共通に軽減した同時攻撃で、低い側も攻撃できる。持越は対局中1回だけ選び、発射で確定し、生き残ると出目が次のターンへ戻る。

0.9.2では採用された案2を基準に画面を整理した。左右の役一覧から背景ウィンドウを外し、明るい文字・細い行線・金色の選択行で可読性を確保した。中央のダイス、役、式、得点の間隔を整え、相手の表示は実ダイスから下へ読む構成にした。役名と状態はNoto Sans JP、ゲーム名と大きな得点はAoboshi Oneを使用する。成立通知はダイスに重ねず、役名の位置に一時表示する。ルールと操作は0.9.1から変更していない。AI生成画像は使用していない。
